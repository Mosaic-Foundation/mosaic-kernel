## What this means in plain English

- You may use, study, change, and share this code for any purpose, including running it in production and charging for it.
- If you share a copy, changed or not, you must share it under the same license, with its source.
- If you run a changed version as a network service, you must offer its source to the people who use it (AGPL section 13). Every space's footer has a **Source code** link for this. If you run modified code, point that link to your source.

## Plugins and space types

Plugins don't have to be AGPL. As an additional permission under section 7 of the AGPL, the Mosaic Foundation allows a plugin (a package that adds a process, a feature or an identity method to a space) that works with the kernel only through the published plugin SDK and package contract to be licensed under any terms its author chooses. Running a plugin in a space, or building and testing it with the plugin SDK and conformance suite, does not by itself bring the plugin under the AGPL.

The AGPL still applies to the kernel itself, including the kernel code carried inside the plugin SDK, and to any changes you make to them.
